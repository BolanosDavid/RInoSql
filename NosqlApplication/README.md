# NosqlApplication

- Aplicación gráfica para resultados de consultas en Neo4j
- Disponible por GUI y por consola

## Configuración
- Utiliza la configuración por defecto vista en clase:
- NEO4J_URI=bolt://localhost:7687
- NEO4J_USER=neo4j
- NEO4J_PASSWORD=your_password (usa neo4j por defecto)
- (optional) NEO4J_DB=neo4j

## Menu (En caso de usar la de por consola)
- 0) Reset/Create demo graph (runs create.cypher from resources)
- 1..6) Run example queries
- 9) Export last printed result to TXT
